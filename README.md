# 🤖 2050 미래 로봇 박람회: 프롬프트 제작소 & 로봇 박람회 전시관 웹앱

학생들이 **'2050년 미래 사회 문제를 해결하는 로봇'**을 기획하고, **캔바(Canva) AI**를 활용해 로봇의 외형과 기능이 한눈에 드러나는 단일 소개 영상을 제작·전시할 수 있도록 돕는 수업용 웹앱입니다.

데이터는 **브라우저 LocalStorage(기본 즉시 작동)** 및 **Google Apps Script(구글 스프레드시트 실시간 양방향 동기화)**와 완벽하게 연동됩니다.

---

## 🌟 주요 기능 구성 (3개 탭 구조)

### 1. [탭 1] 🛠️ 프롬프트 제작소 (학생 개별 비공개 작업 공간)
- **학번 & 이름 기반 개별 로그인**: 본인이 작성한 내용과 선생님의 피드백만 볼 수 있으며, 다른 친구들의 작성 내용은 비공개로 보호됩니다.
- **상단 실시간 상태 배지 & 피드백 배너**: `작성중`, `제출완료`, `🚨 수정요청 도착!`, `✅ 전시승인` 상태와 선생님의 피드백 메시지가 실시간으로 상단에 표시됩니다.
- **5단계 구조화 입력 폼 & `[+ 예시 태그 버튼]` & `[💡 실시간 구체화 코칭 질문]`**:
  1. **로봇 이름 & 외형 특징** *(외형 특징 15자 미만 시 주황색 코칭 질문 표시)*
  2. **제작 목적 (해결할 미래 사회 문제)** *(15자 미만 시 주황색 코칭 질문 표시)*
  3. **주요 기능 (작동 모습과 기계적 구조)** *(20자 미만 시 주황색 코칭 질문 표시)*
  4. **탑재된 감지 장치 (4-1 센서명 / 4-2 세부 감지 대상 / 4-3 감지 정보 활용 방법)** *(4-2 또는 4-3이 10자 미만 시 주황색 코칭 질문 표시)*
  5. **적용된 과학 기술 (융합 기술)** *(15자 미만 시 주황색 코칭 질문 표시)*
- **2종 프롬프트 자동 변환 출력기 (`[✨ 프롬프트 자동 변환하기]`)**:
  - **[결과 1] 🎬 캔바 AI 단일 영상 생성용 통합 프롬프트**: 지정된 시각 묘사 템플릿으로 자동 조합 + `[📋 영상 프롬프트 복사하기]` 버튼 제공.
  - **[결과 2] 📋 로봇 박람회 전시용 개조식 기획서**: 박람회 부스 안내판 규격(`🤖 출품 로봇명 & 외형`, `🎯 개발 배경 및 목적`, `⚙️ 핵심 작동 기능 및 구조`, `📡 스마트 감지 메커니즘`, `🔬 적용 융합 과학기술`)으로 변환 + `[🏛️ 로봇 박람회 전시관으로 설명 전달 및 교사 제출]` 버튼 제공.

### 2. [탭 2] 🏛️ 미래 로봇 박람회 전시관 (전체 공유 갤러리)
- 프롬프트 제작소에서 제출된 개조식 로봇 기획서들이 박람회 부스 카드 형태로 전시됩니다.
- **영상 첨부 기능 (`[🎥 캔바 제작 영상 첨부하기]`)**:
  - **로컬 MP4 영상 파일 업로드**: 브라우저 IndexedDB에 저장되어 새로고침해도 유지됩니다.
  - **캔바(Canva) 공유 링크 / 영상 URL 등록**: 캔바 공유 링크를 붙여넣으면 자동으로 임베드 플레이어로 변환됩니다.
  - **AI 시뮬레이션 영상 프리셋**: 수업 시연 및 즉시 테스트용 홀로그램 작동 시뮬레이터를 제공합니다.
- **부스 상세 관람 모달**: 부스 카드를 클릭하면 **좌측에는 로봇 소개 영상 플레이어**, **우측에는 일목요연한 개조식 로봇 기획서**가 나란히 표시됩니다.

### 3. [탭 3] 🔒 교사 관리자 화면 (초기 비밀번호: `1234`)
- **실시간 제출 현황 요약 카드 & 필터**: `전체` / `작성중` / `제출완료` / `수정요청` / `전시승인` 학생 수 집계 및 클릭 필터링.
- **학생별 프롬프트 상세 열람 및 피드백 발송**:
  - `[🔄 수정 요청 보내기]`: 상태를 `수정요청`으로 변경하고 학생의 [탭 1] 상단에 수정 요청 배너를 띄웁니다.
  - `[✅ 전시 승인]`: 상태를 `전시승인`으로 변경합니다.
- **작성 내용 수정 이력 (`[🕒 수정 이력 보기]`)**:
  - 학생이 다시 제출할 때마다 기존 데이터가 덮어씌워지지 않고 `버전 1 (최초 제출)`, `버전 2 (1차 수정)`, `버전 3 (2차 수정)` 형태로 누적 저장되며, 버전 간 변화 과정(Before ➔ After)을 한눈에 비교할 수 있습니다.

## 🧪 초기 탑재 테스트용 더미 데이터 (4명)

앱을 열자마자 모든 시나리오를 즉시 테스트할 수 있습니다:
1. **`10101 김미래` (`전시승인` · 버전 2 완료)**: 버전 1(모호한 작성) ➔ 교사 수정 요청 ➔ 버전 2(구체적 작성) 및 박람회 전시·영상 등록 완료 샘플.
2. **`10102 이로운` (`수정요청` · 버전 1)**: 버전 1 제출 후 교사의 수정 요청이 도착한 상태. [탭 1] 입장 시 상단 수정 요청 강조 배너와 주황색 코칭 박스를 즉시 확인할 수 있습니다.
3. **`10103 박지후` (`제출완료` · 버전 2)**: 교사 수정 요청을 반영해 버전 2를 다시 제출하여 교사 검토 대기 중인 샘플.
4. **`10104 최하늘` (`작성중` · 미제출)**: 일부 항목만 입력 중인 상태.

## ☁️ Google 스프레드시트 실시간 연동 방법 (3분 완성)

1. [Google Drive](https://drive.google.com)에서 새 **Google 스프레드시트**를 만듭니다.
2. 상단 메뉴 **[확장 프로그램] ➔ [Apps Script]**를 클릭합니다.
3. 기존 코드를 지우고 이 폴더의 **[google_apps_script.js](./google_apps_script.js)** 파일 내용을 모두 복사해 붙여넣은 뒤 저장(`Ctrl + S`)합니다.
4. 우측 상단 **[배포] ➔ [새 배포]**를 클릭합니다:
   - 유형 선택: **웹 앱**
   - 다음 사용자 권한으로 실행: **나 (내 계정)**
   - 액세스 권한이 있는 사용자: **모든 사용자 (Anyone)** *(필수)*
5. 생성된 **웹 앱 URL (`https://script.google.com/macros/s/.../exec`)**을 복사합니다.
6. 웹앱 상단 상태 배지 또는 **[탭 3: 교사 관리자 화면] ➔ [☁️ 구글 앱스 스크립트 연동 설정]** 버튼을 눌러 URL을 붙여넣고 저장하면 즉시 실시간 양방향 동기화가 시작됩니다!
